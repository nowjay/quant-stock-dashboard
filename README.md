# QUANT — 주식 분석 대시보드

**🔗 배포 주소: https://nowjay.github.io/quant-stock-dashboard/** (모바일 대응)

관심종목 · 실시간 차트 · AI 목표주가 분석 · 글로벌 매크로 일정/뉴스를 한 화면에서 보는 라이트 테마 대시보드입니다.

```bash
python3 -m http.server 8777    # 프로젝트 폴더에서 실행 후 http://localhost:8777
```

> 모듈이 `<script src>`로 분리돼 있어 `file://`이 아닌 로컬 서버로 열어야 합니다.

```bash

python3 tools/build_events.py       # FOMC · BLS 지표 발표일 · 실적 발표일 · 컨센서스
```

## 기능

### 1. 통화 표기 · 원화 환산
국내 종목은 `286,500원`, 미국 종목은 `$335.92` 로 통화를 명시합니다.
미국 종목은 현재 환율로 환산한 `≈ 459,800원 · $1 = 1,369원`을 함께 보여줍니다(환율 출처·기준일은 툴팁).

### 2. 실시간 시세
연결 우선순위는 **WebSocket → REST 1초 폴링 → 모의 시세**입니다.

- `assets/feed/kis.js` — 한국투자증권 KIS 실시간 체결가(`H0STCNT0`) 파서, PINGPONG 응답, 지수 백오프 재연결(최대 5회)
- `assets/feed/toss.js` — 토스증권 Open API (WebSocket 또는 REST 폴링)
- `assets/feed/mock.js` — 랜덤워크 모의 시세 (연동 전/실패 시 자동 전환)
- `assets/feed/index.js` — 위 셋을 고르고 폴백하는 파사드. 15초간 체결이 없으면 워치독이 재연결

차트 우상단에 **`🟢 실시간 수신 중 · 14:03:21`** 배지로 상태와 마지막 수신 시각을 표시합니다.

> ⚠️ 브라우저에서 증권사 API를 직접 호출하면 CORS로 차단되고, HTTPS 페이지에서는 `ws://`도 차단됩니다.
> 실거래 연동에는 토큰을 보관하고 `wss://`로 중계하는 **프록시 서버가 필요**합니다.

### 3. 글로벌 매크로 뉴스 & 주요 일정
우측 패널 `글로벌 매크로` 탭은 개별 종목이 아니라 **증시 전체에 영향을 주는 일정과 뉴스**를 모아 보여 줍니다.
모든 시각은 실제 발표 순간으로 계산해 **한국시간**으로 표기하며, 미국 발표는 서머타임을 반영합니다.

- **다음 핵심 이벤트 카운트다운** — FOMC · 미국 CPI · 고용보고서 · 한국은행 금통위 중 가장 가까운 일정의 D-Day와 초 단위 카운트다운
- **주요 매크로 타임라인** — FOMC 금리 결정(점도표 회의 표시)·의사록, 미국 CPI · PPI · 고용 · PCE · GDP · ISM,
  한국은행 기준금리 · 한국 물가 · 수출입동향, 국내/미국 파생 만기. `금리 · 물가 · 고용·경기 · 만기` 필터와 중요도(●●●) 표시
- **실적 시즌 캘린더** — JP모건 · TSMC · 넷플릭스 · 테슬라 · 마이크로소프트 · 알파벳 · 메타 · 애플 · 아마존 · 엔비디아 등
  빅테크와 삼성전자 · SK하이닉스 · 현대차를 주 단위로 묶어 표시 (미국 기업은 현지 발표일과 한국시간을 함께 표기, 누르면 해당 종목 차트로 이동)
- **증시 뉴스 피드** — 언론사 RSS를 `금리/물가 · 실적 · 증시동향`으로 자동 분류한 카드. 탭이 열려 있는 동안 5분마다 갱신

> 브라우저는 언론사 RSS를 직접 읽을 수 없어(CORS) 중계가 필요합니다. 기본값은 rss2json 공개 API이며,
> 설정(톱니) → **뉴스 피드**에서 자체 프록시(`https://my-server/rss?url={url}`)로 바꾸거나 끌 수 있습니다.
> 연결에 실패하면 `tools/build_news.py`로 수집한 `assets/data/news.json` 스냅샷을 표시합니다.

### 4. 검색 · 자동완성
`assets/core/search.js` 가 **한글명 · 영문명 · 종목코드 · 초성**을 모두 인덱싱합니다.

- `ㅅㅅㅈㅈ` → 삼성전자, `ㅋㅋㅇㅂㅋ` → 카카오뱅크
- `005930`, `AAPL`, `hynix` 모두 매칭
- 입력 즉시 드롭다운이 열리고 `↑↓` 이동, `Enter` 선택, `Esc` 닫기

### 기술적 분석 · AI 목표주가
12개 지표(이동평균 6 + 오실레이터 6) 종합 점수 게이지, 골든/데드크로스, RSI 과매수·과매도,
MACD 시그널 교차, 피봇 기준 지지·저항 2단계를 제공합니다.

**AI 목표주가**는 단기(1~2주) · 중장기(1~3개월)로 나누어 `보수적(Bear) · 기본(Base) · 공격적(Bull)` 3개 시나리오와
현재가 대비 상승 여력(%)을 보여 줍니다. 산정 방식(`assets/core/targets.js`, 항상 일봉 기준):

1. **후보 레벨 수집** — 52주 신고가/신저가, MA50·MA200 박스 상·하단, 볼린저 상한선, 피봇 R1/R2(일간·주간·월간),
   전고점/전저점(스윙), 52주 주파동과 이후 조정/반등 파동의 피보나치 되돌림·확장 레벨
2. **도달 예상 지점** — 현재가 + σ√기간 × (시나리오 배수 + 추세 편향). σ는 급등락 하루에 휘둘리지 않도록
   MAD 기반 변동성과 최근 20일 변동성을 섞은 값, 추세 편향은 단기/중기 방향 점수(−1~+1)
3. **레벨 앵커링** — 도달 예상 지점 근처의 가장 유력한 기술적 레벨(합류 구간 우선)을 목표가로 채택하고, 없으면 변동성 투영값 사용
4. **손절가** — 의미 있는 지지선 아래 ATR 버퍼 (단기 0.3 ATR · 중장기 0.5 ATR)

Base·Bull은 항상 현재가 위이며, 현재가 아래 목표는 추세가 뚜렷하게 약할 때 Bear 시나리오에서만 나옵니다.
각 시나리오에는 근거 레벨과 변동성 기준 도달 확률을 함께 표시하고, 차트에 단기/중장기 목표가와 손절가 가이드선을 그립니다.

**목표주가 산정 근거** 카드는 ① 기술적 분석 이유(20일선 돌파·MA 박스·52주 위치·파동) ② 보조지표 상태(RSI · MACD · 스토캐스틱 ·
볼린저 %B · 거래량) ③ 리스크 및 손절가(단기/중장기 손절가, 1·2차 지지선, 과열·매물대·변동성·임박한 매크로/실적 이벤트)를 문장으로 설명합니다.
국내 종목은 증권사 컨센서스 목표주가와도 비교합니다.

## 구성

```
index.html                     화면 마크업
assets/css/app.css             라이트 테마 토큰 · 레이아웃
assets/core/market-data.js     종목 마스터 · 시세 · 봉 집계 · 틱 반영
assets/core/indicators.js      SMA/EMA/볼린저/RSI/MACD/Stoch/CCI/Williams/ATR
assets/core/analysis.js        종합 점수 · 크로스 · 피봇 · 전망 문장
assets/core/targets.js         파동 기반 목표주가(Bear/Base/Bull) · 손절가 · 산정 근거
assets/core/search.js          초성 포함 검색 인덱스
assets/core/events.js          매크로 일정 · 실적 시즌 캘린더 (확정·규칙·예상, 한국시간)
assets/core/news.js            증시 뉴스 피드 (RSS 중계 · 스냅샷 · 카테고리 분류)
assets/core/fx.js              USD/KRW 환율
assets/feed/{kis,toss,mock,index}.js   실시간 피드 어댑터와 파사드
assets/data/*.json             수집된 종목·시세·일봉·일정 데이터
tools/build_*.py               데이터 수집 스크립트
legacy/terminal-dark.html      초기 다크 터미널 버전
```

## 설정

우상단 톱니 → **실시간 시세 연결**에서 데이터 소스(모의 / KIS / 토스), 프록시 주소, 토큰, WebSocket 주소와
뉴스 피드 수신 방식을 설정합니다(브라우저 localStorage 저장). 로컬 개발에서는 `config.local.js`(gitignore)로도 지정할 수 있습니다.
