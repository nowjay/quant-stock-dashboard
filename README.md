# QUANT — 주식 분석 대시보드

**🔗 배포 주소: https://nowjay.github.io/quant-stock-dashboard/** (모바일 대응)

글로벌 지수 전광판 · 환율/원자재/금리 · 공포 & 탐욕 지수 · 매크로 D-Day를 한눈에 보는 **스마트 홈**과,
관심종목 · 실시간 차트 · AI 목표주가 분석 · 재무 가치분석 · 추천 종목 스크리너 · 글로벌 매크로 일정/뉴스를 보는 **종목 분석** 화면,
채권 · 기술적 분석 · 가치 분석 등 투자 개념을 익히는 **주식 공부** 화면으로 구성된 라이트 테마 대시보드입니다.

```bash
python3 -m http.server 8777    # 프로젝트 폴더에서 실행 후 http://localhost:8777
```

> 모듈이 `<script src>`로 분리돼 있어 `file://`이 아닌 로컬 서버로 열어야 합니다.

## 차트 · 분석 데이터: 공공데이터포털 + 토스증권 실시간

배포본(공유용 웹앱)의 **국내 종목 차트와 기술적 분석은 공공데이터포털 [금융위원회_주식시세정보](https://www.data.go.kr/data/15094808/openapi.do)** 로 이루어집니다.
공공데이터는 누구에게나 다시 보여 줄 수 있어서, 사이트를 여는 모든 방문자가 같은 실제 데이터를 봅니다.
**토스증권 Open API를 연결하면** 그 위에 실시간 주가 · 오늘 봉 · 실제 1분봉이 더해집니다(각자 본인 키).

| 방문자 | 국내 종목 차트 · 분석 | 현재가 | 분봉 |
|---|---|---|---|
| 토스 미연결 (기본) | 공공데이터 일봉 2년치 (수정주가) | 공공데이터 **전 영업일 종가** · `공공데이터` 표시 | 제공하지 않음 (1분/5분 버튼 비활성) |
| 토스 연결 | 공공데이터 일봉 + 그 이후 거래일은 토스 일봉 | **토스 실시간 체결** | 토스 실제 1분봉 |

- 공공데이터는 **영업일 다음 날 오후 1시 이후**에 전날 시세가 올라옵니다(T+1). 배포 워크플로가 평일 13:40 · 17:30 KST에 새 날짜를 받아 다시 배포합니다.
- 액면분할 · 무상증자처럼 기준가가 바뀐 날은 이전 가격을 같은 비율로 조정합니다(`기준가 = 종가 − 대비`와 전일 종가 비교).
- 공공데이터를 받지 못한 종목(예: ETF — `금융위원회_증권상품시세정보`를 따로 신청하지 않은 경우)은 아래 번들 데이터로 대신합니다.
- 미국 종목은 공공데이터에 없어 기존대로 Yahoo Finance 번들 + 토스 일봉을 씁니다.

### 공공데이터 서비스키 설정 (처음 한 번)

1. [공공데이터포털](https://www.data.go.kr) 로그인 → `금융위원회_주식시세정보` 검색 → 오픈API **활용신청** (자동 승인).
   ETF도 공공데이터로 보려면 `금융위원회_증권상품시세정보`도 신청합니다(같은 키 사용).
2. 마이페이지 → 개발계정 → **일반 인증키(Decoding)** 복사. 신청 직후에는 활성화까지 1시간 정도 걸릴 수 있습니다.
3. GitHub 저장소에 Secret으로 등록 — 배포 워크플로만 읽고 페이지에는 노출되지 않습니다.
   ```bash
   gh secret set DATA_GO_KR_KEY -R nowjay/quant-stock-dashboard
   ```
4. 다시 배포: Actions → `pages` → Run workflow (첫 실행은 2년치 약 520일을 받느라 10~20분 걸리고, 이후에는 새 날짜만 받습니다)
5. 로컬에서 확인하려면 `.env`에 `DATA_GO_KR_KEY=…`를 넣고 `python3 tools/build_krx.py` 실행 후 로컬 서버로 엽니다.

개발 계정의 호출 한도는 하루 1만 건입니다. 날짜당 1~2건만 쓰므로(첫 수집 약 1,000건, 이후 배포마다 10~20건) 충분합니다.

### 배포 구조

```
GitHub Actions (pages.yml) ── 공공데이터 API ──▶ .cache/krx/<날짜>.json (actions/cache, 새 날짜만 추가)
                           └─ tools/build_krx.py ─▶ assets/data/krx/quotes.json · d/<코드>.json (종목당 약 20KB)
                           └─ 사이트 전체와 함께 GitHub Pages 에 배포
브라우저 ── 종목을 열 때 d/<코드>.json 만 받음 ── (토스 연결 시) 이후 거래일 · 실시간 체결 · 1분봉을 토스 프록시에서
```

종목별 일봉 파일(수천 개)은 **커밋하지 않습니다**. 매일 새로 쓰면 저장소가 1년에 수 GB씩 불어나기 때문에,
GitHub Pages 소스를 `GitHub Actions`로 두고 배포할 때마다 만듭니다. `pages` 워크플로는 main 푸시 · `build-data` 수집 직후 · 평일 예약 · 수동 실행 때 돕니다.

데이터는 `tools/build_*.py`로 언제든 재수집할 수 있습니다.

```bash
python3 tools/build_markets.py      # 홈 대시보드: 지수 · 환율 · 원자재 · 금리 · 공포/탐욕 · 심리지수 · 예상치
python3 tools/build_dataset.py      # 국내 전종목 + 대표 일봉
python3 tools/build_us.py           # 미국 종목 보강 + 대표 일봉
python3 tools/build_events.py       # FOMC · BLS 지표 발표일 · 실적 발표일 · 컨센서스
python3 tools/build_news.py         # 증시 뉴스 스냅샷 (실시간 피드 실패 시 대체)
python3 tools/build_fundamentals.py # 재무 · 가치분석 (약 15분, 종목 코드를 넘기면 그 종목만 갱신해 병합)
python3 tools/build_krx.py          # 공공데이터 일봉 (.env 의 DATA_GO_KR_KEY 필요 · 결과는 커밋하지 않음 — 배포 때 자동 생성)
```

GitHub Actions(`build-data`)가 평일 한국장 중 3회 · 장 마감 직후(15:45) `markets`를, 매일 06:40 KST에
`markets events news`를, 매주 월요일 07:20 KST에 `fundamentals`를 예약 실행해 `assets/data/`를 갱신합니다.

## 기능

### 스마트 홈 대시보드
상단 `홈 | 종목 분석 | 주식 공부` 전환의 첫 화면입니다(마지막으로 본 화면을 기억). 관심종목 사이드바는 그대로 두어,
종목을 누르면 바로 종목 분석 화면으로 넘어갑니다.

- **글로벌 지수 전광판** (모든 화면 최상단) — 국내(코스피 · 코스닥 · 코스피200 선물) · 미국(나스닥 · S&P500 · 다우 ·
  나스닥100 선물 · S&P500 선물 · 필라델피아 반도체 · VIX) · 아시아(니케이 · 상해 · 대만 가권). 현재값 · 전일 대비 · 등락률 ·
  1개월 스파크라인, 시장별 `장중 / 프리마켓 / 장 마감` 상태. 가로 스크롤(데스크톱은 화살표 버튼)
  **그래프 기간**(1개월 · 3개월 · 6개월 · 1년) 버튼으로 모든 지수의 미니 그래프를 한꺼번에 바꾸고, 그래프 아래에 그 기간의 변동률을 표시합니다
  (선 색은 기간의 방향, 카드의 등락 숫자는 전일 대비 그대로). 고른 기간은 브라우저에 저장되며, 카드를 눌러 여는 추세 팝업도 같은 기간으로 시작합니다.
- **환율 · 원자재 · 금리** — 원/달러 · 원/100엔 · 달러 인덱스 · WTI · 금 · 구리 · 미국 10년물/2년물(장단기 금리차) ·
  한국/미국 기준금리(한미 금리차). 카드를 누르면 **추세 차트 팝업**(1개월~1년, 지수·환율·원자재는 5년 주봉까지)
- **공포 & 탐욕 지수 (CNN)** — 반원 게이지, 점수 · 단계(극심한 공포 ~ 극심한 탐욕), 전일/1주/1개월/1년 전 비교, 세부 지표 7개
- **국장 심리지수 (QUANT 자체)** — 코스피 125일선 괴리 · 52주 위치 · RSI · 20일 변동성 · 원/달러 20일 변화 · 코스닥 상대강도를
  최근 1년 분포 대비 백분위(0~100)로 바꿔 평균. 코스피 20일 변동성(1년 평균 대비), 등락 종목 수, 개인/외국인/기관 순매수 함께 표시
- **다가오는 주요 매크로 일정** (데스크톱에서는 우측 고정) — CPI · FOMC · 금통위 · 고용보고서 · PCE · ISM · 빅테크 실적을
  `D-2` 태그로 강조하고 **직전 발표치 → 시장 예상치**를 비교(▲▼). 실적은 전년 동기 EPS → 예상 EPS. 핵심 이벤트 초 단위 카운트다운
- 원/달러는 CNBC 실시간 값이 오면 미국 종목의 원화 환산에도 같은 값을 씁니다

> CNBC 시세 서버는 일부 비표준 브라우저(예: 데스크톱 앱 내장 브라우저)의 요청을 거부합니다. 이때는 수집 스냅샷과
> `수집 기준` 시각을 표시합니다. 일반 Chrome · Safari · Edge에서는 30초마다 갱신됩니다.

### 토스증권 Open API 연결

토스증권 API는 브라우저에서 바로 부를 수 없습니다(REST 응답에 CORS 헤더가 없고, 웹소켓 handshake에
`Authorization` 헤더가 필요하며, `client_secret`을 페이지에 둘 수 없음). 그래서 이 PC에서만 도는
**로컬 프록시**가 토큰을 발급·보관하고 시세만 중계합니다.

```
브라우저 ── http://127.0.0.1:8778/api/v1/... ──▶ toss_proxy.py ──▶ https://openapi.tossinvest.com
브라우저 ── ws://127.0.0.1:8778/ws ────────────▶ toss_proxy.py ──▶ wss://openapi-ws.tossinvest.com/ws/v1
```

1. **키 발급** — 토스증권 WTS 로그인 → 설정 → Open API에서 `client_id` · `client_secret` 발급
2. **허용 IP 등록** — 같은 화면 하단 *허용 IP 관리*에 이 PC의 공인 IP 등록 (미등록 IP는 `403`).
   집 인터넷은 공인 IP가 바뀔 수 있으니 403이 나면 먼저 확인하세요.
3. **`.env` 작성** — `cp .env.example .env` 후 `TOSS_CLIENT_ID` · `TOSS_CLIENT_SECRET` 입력 (`.env`는 gitignore)
4. **프록시 실행**
   ```bash
   python3 -m venv .venv && .venv/bin/pip install aiohttp certifi   # 처음 한 번
   .venv/bin/python tools/toss_proxy.py
   ```
   `연결 확인 완료 — 삼성전자(005930) 현재가 …원`이 보이면 키와 허용 IP가 모두 정상입니다.
5. **대시보드 연결** — 우상단 톱니 → 데이터 소스 `토스증권 Open API` → 프록시 주소 `http://127.0.0.1:8778` → 연결하기

동작
- 연결 시 현재가를 한 번 받아 두고(웹소켓은 초기값을 주지 않음) `trade:kr` / `trade:us` 체결을 구독합니다.
- 국내 종목은 공공데이터 일봉 뒤에 그 이후 거래일(공공데이터 미게시분 · 오늘)만 토스 일봉으로 이어 붙이고,
  체결 시각의 거래일을 보고 오늘 봉을 새로 열어 실시간으로 움직입니다(공공데이터 확정 종가는 건드리지 않음).
- 공공데이터가 없는 종목(미국 등)은 실제 일봉 400개를 받아 차트·지표·전일 대비를 계산합니다.
- 1분 · 5분 차트는 토스 실제 1분봉(약 2거래일, 넥스트레이드 시간 포함)으로 그립니다.
- 프록시↔토스 웹소켓이 끊기면 그동안 REST 1초 폴링으로 메우고, 다시 붙으면 실시간으로 돌아갑니다.
- 체결이 없는 장외 시간에도 연결이 살아 있으면 재연결하지 않습니다(PING/pong으로 확인).
- 프록시 상태 확인: `curl http://127.0.0.1:8778/health`

프록시 안전장치
- `127.0.0.1`에만 바인딩하고, localhost 페이지의 요청·웹소켓만 받습니다(다른 사이트가 몰래 붙지 못함).
- 다른 사이트를 허용(`TOSS_ALLOWED_ORIGINS`)하거나 리버스 프록시를 거쳐 들어온 요청은 **접속 키(`TOSS_PROXY_KEY`) 없이는 거부**합니다.
- **주문·계좌·조건주문 API는 중계하지 않습니다** — 시세·종목·시장 정보 GET만 통과합니다.
- 토큰은 클라이언트당 1개만 유효합니다. 프록시가 새로 발급하면 다른 스크립트에서 쓰던 토큰은 `token-revoked`가 됩니다.
- 토스 웹소켓은 계정당 동시 2개까지라, 탭을 여러 개 열어도 프록시가 업스트림 1개를 공유합니다.

> 토스증권 데이터 이용 정책상 API로 받은 정보는 **본인 매매 목적**으로만 쓸 수 있고 제3자 배포가 금지됩니다.
> 토스 데이터는 브라우저에서 실시간으로만 받고 `assets/data/`나 배포본에 저장하지 않습니다.

### 다른 기기에서 보기 (클라우드 서버)

휴대폰이나 다른 PC(다른 IP)에서도 토스 실시간 데이터를 보려면, **고정 IP 서버**에서 프록시를 24시간 돌리고
배포본(`https://nowjay.github.io/...`)에서 그 서버로 접속합니다. 핫스팟처럼 IP가 자주 바뀌는 문제도 함께 사라집니다.

```
휴대폰·PC 브라우저 ──https + 접속 키──▶ Caddy(HTTPS) ──▶ toss_proxy.py ──▶ 토스증권
                                     └───────── 고정 IP 서버 ─────────┘
```

1. **서버 만들기** (둘 중 하나, Ubuntu 22.04/24.04)
   - AWS Lightsail: 서울 리전 · Linux/Unix · OS 전용 Ubuntu · IPv4 포함 가장 작은 플랜 →
     *네트워킹* 탭에서 **고정 IP 생성·연결**, IPv4 방화벽에 **HTTPS(443)** 추가
   - Oracle Cloud 무료 등급: Ubuntu 인스턴스 · **예약 공인 IP** 연결 · Security List에 80, 443 허용
2. **설치** — 서버 SSH 창에서:
   ```bash
   curl -fsSLO https://raw.githubusercontent.com/nowjay/quant-stock-dashboard/main/tools/server/setup.sh
   sudo bash setup.sh
   ```
   client_id·secret을 물어보고(서버의 `/opt/toss-proxy/.env`에만 저장), 접속 키를 만들어 HTTPS까지 설정합니다.
   도메인은 가입이 필요 없는 `<서버IP>.sslip.io`를 기본으로 씁니다.
3. **허용 IP** — 끝에 출력되는 서버 IP를 토스증권 허용 IP에 등록합니다.
4. **각 기기에서** — 설치 끝에 나오는 **연결 링크**(휴대폰은 **QR**)를 엽니다. 설정창에 주소와 접속 키가 채워지면
   내 서버 주소인지 확인하고 연결하기를 누릅니다(링크만으로 자동 연결되지는 않음). 키는 그 브라우저에만 저장되고,
   링크의 키는 열자마자 주소창에서 지워집니다. 직접 입력: 톱니 → `토스증권 Open API` → 프록시 주소 · 접속 키.
5. **이 PC의 로컬 프록시는 끄세요.** 토큰은 클라이언트당 1개라 두 곳에서 돌리면 서로의 토큰을 무효화합니다.
   이 PC에서도 서버 주소와 키로 연결하면 됩니다.

- 접속 키는 비밀번호입니다. 다른 사람에게 알려주면 토스 데이터를 제3자에게 주는 셈이 됩니다.
- 프록시 코드 갱신: 서버에서 `sudo bash setup.sh`를 다시 실행 (`.env`·도메인 유지). 로그: `sudo journalctl -u toss-proxy -f`

### 기술적 분석 · AI 목표주가
**한눈에 보기** 카드가 현재 상태를 쉬운 문장으로 요약하고, 상황별 대응 포인트(지지선·손절선 기준),
6개 항목 체크리스트, 이 종목의 과거 데이터로 검증한 **신호 신뢰도**를 함께 보여 줍니다. 지표 이름 옆 `?`를 누르면 용어 설명이 나옵니다.

- **국면 인식 종합 점수** (`assets/core/scoring.js`) — 지표를 추세·모멘텀·거래량으로 묶어 −100~+100으로 합산합니다.
  ADX로 추세장/횡보장을 판단해, 추세장에서는 추세 지표 비중을 높이고 과매수 신호는 '과열 경고' 정도로만 반영합니다
  (예전 방식은 이동평균 6개를 따로 세고, 강한 상승 중에도 RSI 70 이상을 무조건 매도로 셌습니다).
- **추가 지표** — ADX·DMI(추세 세기), OBV(누적 거래량 흐름), MFI(거래량 반영 RSI)
- **최근 기술적 신호** (`assets/core/patterns.js`) — 골든/데드크로스, MACD 교차, RSI 다이버전스, 장악형·망치형·유성형·도지 캔들,
  20일 박스권 돌파/이탈(거래량 동반 여부), 거래량 급증. 주요 신호는 차트에 화살표로 표시(`신호` 토글)
- **시간대별 추세 비교** — 일·주·월봉을 따로 분석해 방향이 일치하는지 보여 줍니다
- **백테스트** (`assets/core/backtest.js`) — 같은 계산을 과거 각 날짜에 적용해(미래 데이터 미사용)
  비슷한 신호 뒤 10거래일 수익률, 과거 목표가의 실제 도달률·손절선 선도달률을 종목별로 표시합니다.
  매일 뽑은 표본은 10거래일 구간이 서로 겹치므로 **겹치지 않는 표본 수**로 오차를 계산하고, 아무 날이나 샀을 때(기저)와
  통계적으로 유의하게(95%) 다를 때만 '잘 맞았다 / 안 맞았다'고 표시합니다. 그 밖에는 '우연 범위'로 표시합니다.
- **분석 신뢰도** (`Analysis.quality`) — 예측력이 아니라 지표를 계산한 **데이터의 품질**입니다.
  시뮬레이션 경로 · 거래정지/무거래 · 일봉 60개 미만이면 `낮음`으로 보고 **투자 의견 · 목표가를 내지 않으며**(판단 보류)
  스크리너의 기술 점수에서도 뺍니다. 200일선이 없거나 하루 ±30%를 넘는 급변이 있으면 `보통`으로 주의 문구를 붙입니다.
- **피봇(지지선 · 저항선)** — 끝난 봉의 고가·저가·종가로 다음 봉의 선을 만듭니다. 종가 데이터(공공데이터 · 번들)는
  마지막 거래일이 기준이고, 실시간 체결로 오늘 봉이 움직이는 중에만 전날이 기준입니다. 카드 제목 옆에 기준일을 표시합니다.
  목표가 후보의 주간 · 월간 피봇은 직전에 끝난 **달력 주 · 월** 기준입니다.
- **진행 중인 봉** — 장중의 오늘 봉(주봉 · 월봉은 이번 주 · 달)은 거래량이 다 차지 않았으므로 거래량 점수 · 거래량 비교,
  종가가 정해져야 성립하는 캔들 패턴 · 박스권 돌파는 끝난 봉까지만 계산합니다.

#### 검증 (`tools/verify_ta.js`)
```bash
node tools/verify_ta.js            # 계산 검증 — 지표를 참조 구현과 전 구간 비교, 피봇 · 마감 시각 · 품질 · 확률 · 신뢰도 판정
node tools/verify_ta.js --report   # + 과거 데이터로 실제 적중률 측정 (등급별 수익률 · 도달확률 보정 · 신뢰도 판정 분포)
```
2026-10 측정(국내 시가총액 상위 150 + 번들 미국 종목, 약 1년): 지표 계산은 참조 구현과 일치합니다.
종합 점수 등급은 10거래일 뒤 수익률과 **통계적으로 유의한 관계가 없었습니다** — 등급은 '현재 추세 상태'의 요약이지
수익 예측이 아닙니다. 도달확률은 표시값과 실제의 차이가 단기 기준 약 5%p 안팎입니다(중장기는 상승장 영향으로 실제가 더 높음).

**AI 목표주가**는 단기(1~2주) · 중장기(1~3개월)로 나누어 `보수적(Bear) · 기본(Base) · 공격적(Bull)` 3개 시나리오와
현재가 대비 상승 여력(%)을 보여 줍니다. 산정 방식(`assets/core/targets.js`, 항상 일봉 기준):

1. **후보 레벨 수집** — 52주 신고가/신저가, MA50·MA200 박스 상·하단, 볼린저 상한선, 피봇 R1/R2(일간·주간·월간 — 직전에 끝난 거래일 · 달력 주 · 달력 월),
   전고점/전저점(스윙), 52주 주파동과 이후 조정/반등 파동의 피보나치 되돌림·확장 레벨
2. **도달 예상 지점** — 현재가 + σ√기간 × (시나리오 배수 + 추세 편향). σ는 급등락 하루에 휘둘리지 않도록
   MAD 기반 변동성과 최근 20일 변동성을 섞은 값, 추세 편향은 단기/중기 방향 점수(−1~+1)
3. **레벨 앵커링** — 도달 예상 지점 근처의 가장 유력한 기술적 레벨(합류 구간 우선)을 목표가로 채택하고, 없으면 변동성 투영값 사용
4. **손절가** — 의미 있는 지지선 아래 ATR 버퍼 (단기 0.3 ATR · 중장기 0.5 ATR)
5. **도달확률** — 무추세 랜덤워크의 '기간 안에 한 번이라도 닿을 확률'. 목표가 위치에 쓰는 σ(이상치를 누른 값)는 실제 변동성보다
   작아 먼 목표의 확률이 실제의 절반 수준으로 나오므로, 확률은 절단하지 않은 표준편차(120일 · 20일 혼합)로 계산합니다.
   손절가에도 같은 방식의 도달확률을 표시합니다 — 지지선 바로 아래 손절은 평소 변동만으로 닿는 경우가 절반 안팎입니다.

Base·Bull은 항상 현재가 위이며, 현재가 아래 목표는 추세가 뚜렷하게 약할 때 Bear 시나리오에서만 나옵니다.
각 시나리오에는 근거 레벨과 변동성 기준 도달 확률을 함께 표시하고, 차트에 단기/중장기 목표가와 손절가 가이드선을 그립니다.

**목표주가 산정 근거** 카드는 ① 기술적 분석 이유(20일선 돌파·MA 박스·52주 위치·파동) ② 보조지표 상태(RSI · MACD · 스토캐스틱 ·
볼린저 %B · 거래량) ③ 리스크 및 손절가(단기/중장기 손절가, 1·2차 지지선, 과열·매물대·변동성·임박한 매크로/실적 이벤트)를 문장으로 설명합니다.
국내 종목은 증권사 컨센서스 목표주가와도 비교합니다.

### 가치분석 (펀더멘털)
우측 패널 `가치분석` 탭입니다. 재무 데이터는 `assets/data/fundamentals.json`에서 읽고, 주가에 따라 바뀌는 값
(PER · PBR · 배당수익률 · EV/EBITDA · 적정가 괴리율)은 **현재가(실시간 시세 포함)로 다시 계산**합니다(`assets/core/fundamentals.js`).

- **종합 매수 신호** — 아래 점수를 등급 배지 · 0~100 눈금 · 항목별 막대로 표시. AI 분석 탭 게이지 아래에도 한 줄 요약(누르면 이 탭)
- **AI 가치분석 요약** — 예: *"PER 12.9배로 WICS 반도체와반도체장비 평균(9.1배) 대비 41% 높은 고평가 상태입니다.
  선행 PER은 6.0배로… 최근 3년 영업이익률이 2.5% → 10.9% → 13.1%로 3년 연속 상승 중(우수)입니다."*
- **① 밸류에이션** — PER(업종 대비) · 선행 PER · PBR · ROE · EV/EBITDA(과거 5년 중앙값 대비) · 배당수익률 · PEG · FCF 수익률
- **② 실적 추이** — 연간(3개년 + 컨센서스 추정) / 분기(최근 4~5분기) 매출액 막대 + 영업이익 · 순이익 꺾은선, 전년(동기) 대비 증감 표
- **③ 재무 건전성** — 부채비율 30 · 이자보상배율 30 · 유보율 20 · 유동비율 20점으로 0~100점과 `매우 안정 ~ 위험` 등급, 5개년 추이.
  금융업은 부채비율 · 이자보상배율을 제외
- **④ 적정주가 · 본질가치** — 방법별 범위를 한 눈금에 그린 차트와 가중평균 적정주가
  | 방법 | 계산 | 가중치 |
  |---|---|---|
  | PER 밴드 | 과거 5년 연말 PER의 20% · 중앙 · 80% 분위 × 기준 EPS(선행 EPS, 이익 급변 구간은 최근 4분기 EPS와의 기하평균) | 35% |
  | S-RIM | BPS × [1 + (기대 ROE − Ke) × ω / (1 + Ke − ω)], ω = 0.8 · 0.9 · 1.0. 기대 ROE = 3년 가중 ROE · 최근 4분기 ROE · 선행 ROE 평균 | 30% |
  | PBR 밴드 | 과거 5년 연말 PBR 분위 × BPS | 20% |
  | DCF | 최근 3년 FCF(영업현금흐름 − 설비투자) 가중평균, 5년간 매출 성장률(최대 20%) → 영구성장률로 수렴, Ke로 할인 | 15% |

  요구수익률 Ke = 무위험 금리(국내 3.0% · 미국 4.2%) + β × 위험프리미엄(5.5% · 5.0%), 7~13%로 제한.
  적자(PER), 들쭉날쭉한 현금흐름(DCF), 자본 대비 이익이 과도한 기업(S-RIM, ROE 35%↑ 또는 PBR 6배↑)은 해당 방법을 제외하고 가중치를 재배분합니다.
  증권사 컨센서스 목표가는 참고로만 함께 표시합니다. 과거 배수 × 최근 4분기 EPS · BPS로 그린 **PER · PBR 밴드 차트**도 제공합니다.
- **가치 체크리스트** — 흑자 · ROE 10% · 이익률 개선 · 영업이익 증가 · 부채비율 · 이자보상배율 · FCF · 업종 PER · 배당

### 종합 매수 신호 · 추천 종목 스크리너
`assets/core/signal.js` — 기술 50% + 재무 50%.

| 구분 | 항목 (각 25점) |
|---|---|
| 기술 점수 | 이동평균선 방향(20일선 위 · 20일선 상승 · 20>50일선 · 50>200일선 · 200일선 위) · RSI(구간 + 상승 전환 가점) · MACD(시그널선 위 · 히스토그램 증가 · 0선 위 · 최근 골든크로스) · 피봇 저항 돌파(R2 25 · R1 21 · P 14 · S1 7) |
| 재무 점수 | 업종 대비 PER · 업종 대비 PBR · ROE(10% 이상 18점, 15% 이상 22점, 20% 이상 25점) · 최근 분기 영업이익 전년 동기 대비(흑자전환 포함). 재무 건전성 45점 미만이면 5점, 30점 미만이면 10점 감점 |

**80점 이상 강력 매수 · 65~79 매수 · 45~64 중립 · 30~44 매도 · 30 미만 강력 매도** (기술 · 재무 점수 단독에도 같은 기준).

사이드바 `관심종목` · `시가총액 상위` 탭 위의 **추천 종목만 보기** 토글을 켜면 조건에 맞는 종목만 점수 순 카드로 보여 줍니다.

- 필터: `강력 매수만` / `매수 이상 전체`, 분석 기준 `기술적` / `재무 가치` / `종합`
- 카드: 종목명 · 현재가 · 등락률 · 등급 배지(강력 매수 진한 초록 · 매수 연한 초록) · 추천 이유 태그(`#PER저평가` `#RSI과매도` `#골든크로스발생` 등) ·
  상승 여력(재무 · 종합 기준은 적정주가, 기술 기준은 중장기 기술적 목표가)
- `시가총액 상위` 탭에서는 시장 필터(코스피 · 코스닥 · ETF · 미국) 안의 **분석 가능한 전 종목**을 훑습니다
- 기술 · 종합 기준은 실제 일봉이 있는 종목만, 재무 · 종합 기준은 재무 데이터가 있는 종목만 평가하고 제외 수를 표시합니다
- 3초마다 가격이 바뀐 종목만 다시 평가해 순위 · 등급을 갱신합니다(종목별 캐시)

> 미국 종목은 nasdaq.com이 최근 4분기만 제공해 **최근 분기 전년 동기 비교가 불가능**하므로, 영업이익 증감을 최근 회계연도 기준으로 대신합니다(화면에 기준 표기).

## 설정

우상단 톱니 → **실시간 시세 연결**에서 데이터 소스(공공데이터 종가 / 토스 / KIS / 모의 데모), 프록시 주소, WebSocket 주소와
뉴스 피드 수신 방식을 설정합니다(브라우저 localStorage 저장). 로컬 개발에서는 `config.local.js`(gitignore)로도 지정할 수 있습니다.
토스증권 키는 브라우저가 아니라 `.env`에 둡니다.

## 면책

모든 지표·전망·목표가는 과거 가격의 수학적 계산 결과이며 투자 자문이 아닙니다. 주식 공부의 내용은 학습용 일반 정보이며,
세율 · 거래 제도는 기준 시점 이후 바뀔 수 있습니다. 투자 판단과 책임은 이용자 본인에게 있습니다.
