토스증권 실시간 시세 연결하기

이 대시보드의 차트와 분석은 누구나 공공데이터포털(금융위원회) 전 영업일 종가로 볼 수 있고, 실시간 주가(오늘 봉 · 1분봉 포함)는 각자 본인의 토스증권 Open API 키로 연결해야 보입니다. 한 번 설정해 두면 휴대폰·PC 어디서든 내 시세가 뜹니다.

ℹ️ 토스증권 약관상 API로 받은 정보는 본인 매매 목적으로만 쓸 수 있고, 다른 사람에게 보여주거나 나눠줄 수 없습니다. 그래서 한 사람의 키로 모두에게 보여주지 않고, 각자 자기 키로 자기 화면에만 받습니다.

준비물

  • 토스증권 계좌Open API 키를 발급받을 본인 계좌
  • 클라우드 서버 1대AWS Lightsail(유료, 소액) 또는 Oracle Cloud 무료 등급
  • 20~30분명령어는 복사·붙여넣기 두 줄

설정 순서

  1. 토스증권 Open API 키 발급

    PC에서 토스증권 웹(WTS)에 로그인 → 설정 → Open API에서 client_id와 client_secret을 발급받습니다.

    • 화면의 복사 버튼으로 복사해 두세요. 앞뒤 공백이 섞이면 인증이 실패합니다.

  2. 서버 만들기 (고정 IP)

    토스증권은 등록한 IP에서만 API를 허용하므로, IP가 바뀌지 않는 서버가 필요합니다.

    • AWS Lightsail — 리전 서울, Linux/Unix, OS 전용 → Ubuntu 24.04, IPv4가 포함된 가장 작은 플랜으로 생성 → 네트워킹 탭에서 고정 IP 생성·연결, IPv4 방화벽에 HTTPS(443) 추가
    • Oracle Cloud 무료 등급 — Ubuntu 인스턴스 생성 → 예약 공인 IP 연결 → Security List에 TCP 80·443 허용

  3. 프록시 설치

    서버 콘솔의 SSH로 연결 창에서 아래 두 줄을 차례로 붙여넣습니다.

    curl -fsSLO https://raw.githubusercontent.com/nowjay/quant-stock-dashboard/main/tools/server/setup.sh
    sudo bash setup.sh
    • client_id, client_secret을 물어보면 붙여넣습니다. secret은 입력해도 화면에 보이지 않는 게 정상입니다.
    • 나머지 질문은 Enter로 기본값을 쓰면 됩니다. 키는 내 서버에만 저장됩니다.
    • 끝나면 서버 IP · 연결 링크 · QR 코드가 나옵니다.

  4. 허용 IP 등록

    설치 끝에 나온 서버 IP를 토스증권 WTS 설정 → Open API → 허용 IP 관리에 등록합니다.

  5. 기기마다 연결

    휴대폰은 QR 코드를 찍고, PC는 연결 링크를 엽니다. 설정창에 주소와 접속 키가 채워져 있으면 주소가 내 서버인지 확인하고 연결하기를 누르세요.

    • 직접 입력하려면: 대시보드 우상단 톱니 → 데이터 소스 토스증권 Open API → 프록시 주소와 접속 키 입력
    실시간토스증권 일봉

    화면 우상단에 실시간, 종목 이름 옆에 토스증권 일봉이 보이면 연결된 것입니다.

안 될 때

"허용 IP 가 아닙니다"4단계에서 등록한 IP가 설치 끝에 나온 서버 IP와 같은지 확인하세요. 서버에 고정 IP를 연결하기 전에 설치했다면 IP가 바뀌었을 수 있습니다.
"client_id / client_secret 이 틀렸습니다"서버에서 sudo rm /opt/toss-proxy/.env 후 sudo bash setup.sh를 다시 실행해 복사 버튼으로 붙여넣으세요.
"프록시에 연결할 수 없습니다"클라우드 콘솔 방화벽에서 TCP 80·443이 열려 있는지 확인하세요. 인증서 로그: sudo journalctl -u caddy -n 30
"접속 키가 틀렸습니다"연결 링크를 다시 열거나, 서버에서 sudo bash setup.sh를 다시 실행하면 링크가 다시 나옵니다.
서버 로그에 "토큰이 무효화됐습니다"같은 키로 프록시를 두 곳(예: 내 PC와 서버)에서 돌리고 있습니다. 토큰은 계정당 1개라 한 곳만 켜 두세요.
그 밖의 문제서버에서 sudo journalctl -u toss-proxy -f로 로그를 확인하세요.
접속 키와 연결 링크는 비밀번호입니다.
  • 다른 사람에게 보내지 마세요. 공유하면 내 토스 데이터를 남에게 주는 셈이 되어 약관 위반입니다. 친구는 이 안내대로 자기 키를 만들면 됩니다.
  • 프록시는 시세 조회만 중계하고 주문·계좌 API는 막혀 있어, 키가 새더라도 주문은 할 수 없습니다.
  • 시세는 서버나 이 사이트에 저장되지 않고 내 브라우저에만 표시됩니다.
