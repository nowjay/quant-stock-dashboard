실시간 시세 연결

차트와 분석은 공공데이터포털 금융위원회_주식시세정보(전 영업일 종가, 매일 오후 1시 이후 갱신)로 이루어집니다. 토스증권 Open API 를 연결하면 그 위에 실시간 주가와 오늘 봉 · 1분봉이 더해집니다. 연결에 실패하면 공공데이터 종가로 돌아갑니다.

브라우저에 저장한 토큰은 이 페이지를 여는 누구나 볼 수 있습니다. 실제 운영에서는 프록시 주소만 입력하고 토큰은 서버에 두세요.
연결 링크의 주소와 접속 키를 채웠습니다. 가 내가 만든 서버가 맞는지 확인한 뒤 연결하기를 누르세요.
토스증권 실시간 시세는 각자 본인의 토스증권 Open API 키로만 볼 수 있습니다. 내 서버에 프록시를 설치한 뒤 그 https:// 주소와 접속 키를 입력하세요. 설정 방법 보기 →
서버가 토큰을 보관하고 시세만 중계하는 방식입니다. 입력하면 토큰 필드는 사용하지 않습니다.
이 브라우저에만 저장됩니다(localStorage). 공유 PC에서는 사용하지 마세요.
KIS 실시간은 ws://ops.koreainvestment.com:21000 이지만, HTTPS 페이지에서는 wss:// 프록시가 필요합니다.
